## 隱私權政策

【微樂客／公司全名】（以下稱「本公司」）非常重視您的隱私。本政策說明「數位應援
便利貼」活動（以下稱「本活動」）如何蒐集、處理及利用您的個人資料。

參加本活動前，請您詳細閱讀本政策。當您以 LINE 帳號登入並送出便利貼，即表示
您已閱讀、瞭解並同意本政策的全部內容。

**最後更新日期：【YYYY-MM-DD】**

---

### 一、我們蒐集哪些資料

#### 1. 您的 LINE 帳號資料

當您按下「送出」並完成 LINE 登入時，我們會透過 LINE Login 取得：

| 項目 | 說明 |
|---|---|
| LINE 使用者識別碼（User ID） | 一串由 LINE 產生的專屬代碼，**不是您的 LINE ID，也不能用來反查您的帳號** |
| 顯示名稱（暱稱） | 您在 LINE 上設定的名稱，我們最多保留前 12 個字 |
| 大頭貼 | 您在 LINE 上設定的頭像縮圖 |

我們**不會**取得您的電子郵件、電話號碼、LINE 好友名單、聊天記錄，
也**無法**代您發送任何 LINE 訊息。

#### 2. 您建立的便利貼內容

包含您輸入的文字、手繪塗鴉、選用的貼紙與版面設定，以及送出的時間。

#### 3. 位置資訊（僅在活動開啟店內限定時）

若本活動設定為「限店內參加」，送出便利貼時瀏覽器會請求您的定位權限。
**您的座標只在當下用來判斷是否位於指定範圍內，判斷完即丟棄，不會被傳送或儲存。**
您可以拒絕定位權限，但在店內限定期間將無法送出便利貼。

#### 4. 投稿次數紀錄

為了執行「每人每日投稿上限」，我們會記錄您最近一次送出的時間與當日已送出的張數。

#### 5. 網站使用資訊

我們使用 Google Tag Manager 與相關分析工具，蒐集瀏覽器類型、瀏覽頁面、
停留時間等不會直接識別您身分的統計資料。

---

### 二、我們為什麼蒐集這些資料（蒐集目的）

1. **確認參加資格、避免重複與惡意投稿** —— 這是需要登入的唯一原因。
2. **在店內 LED 牆與活動網站展示您的便利貼。**
3. **維護活動內容的妥適性**（違規內容的辨識與下架）。
4. **活動成效統計**（以不可識別特定個人的彙總數字呈現）。

我們**不會**將您的資料用於行銷推播，也**不會**販售或出租給第三方。

---

### 三、哪些內容會被公開

> **這一段請務必看清楚。**

- 您送出的便利貼（文字、塗鴉、貼紙）會在**店內 LED 牆輪播展示**，
  並輪流放大顯示約 15 秒。
- 便利貼同時會出現在**本活動網站的公開便利貼牆上**，任何人都能瀏覽，
  不需要登入。
- 您的 **LINE 使用者識別碼不會公開**，僅供本公司內部辨識投稿者之用。
- 您的 **LINE 暱稱與大頭貼預設不會顯示在便利貼上**。
  【若之後開放「名牌貼紙」功能，請改為：只有在您主動將名牌貼紙放到便利貼上時，
  您的暱稱與大頭貼才會隨便利貼一起公開展示；不放這張貼紙即為匿名投稿。】

請勿在便利貼上填寫您的真實姓名、電話、地址、身分證字號等個人資訊，
或任何您不希望被公開的內容。

### 四、資料會交給誰、存在哪裡（利用對象、地區與方式）

為了提供本服務，您的資料會由以下受本公司委託的服務提供者處理。
這些服務的伺服器可能位於**台灣以外的地區**：

| 服務提供者 | 處理的資料 | 用途 |
|---|---|---|
| LY Corporation（LINE） | 您的 LINE 帳號驗證 | 身分驗證 |
| Google（Firebase / Google Cloud） | 帳號識別碼、暱稱、大頭貼、便利貼內容 | 資料儲存與帳號管理 |
| OpenAI, L.L.C. | **您在便利貼上輸入的文字** | 自動辨識不當內容 |
| Amazon Web Services | 網站主機 | 網站運作 |
| Google（Tag Manager／Analytics） | 網站使用統計 | 成效分析 |

除上述情形，以及依法令規定或主管機關、司法機關要求之外，
本公司不會將您的個人資料揭露給任何第三方。

### 五、保存多久（利用期間）

- **便利貼內容**：自送出之日起保存至【活動結束後 ◯ 個月】，之後由本公司刪除。
- **LINE 帳號資料**：保存至【活動結束後 ◯ 個月】，或您要求刪除之日止。
- **投稿次數紀錄**（用於執行每人每日投稿上限）：同上。
- **停權紀錄**：若您的帳號因違反活動規範而被停止投稿資格，我們會保留您的
  LINE 使用者識別碼、暱稱與停權紀錄至【活動結束後 ◯ 個月】，以防止再次違規。
  此紀錄**不會**因您請求刪除帳號資料而一併刪除。
- **彙總統計數字**（每日投稿筆數等，不含任何個人資料）：不設保存期限。

### 六、您的權利

依《個人資料保護法》第 3 條，您就本公司保有的您的個人資料，得行使下列權利：

1. 查詢或請求閱覽
2. 請求製給複製本
3. 請求補充或更正
4. 請求停止蒐集、處理或利用
5. 請求刪除

**行使方式**：請來信【聯絡信箱】或致電【聯絡電話】，並說明您要行使的項目。
為保護您的權益，我們可能需要先確認您的身分。本公司將於收到請求後
【◯ 個工作天】內回覆。

> 內部作業：後台「會員」分頁的清單、或「便利貼管理」裡點任一張卡片的投稿者，
> 都會打開該會員的面板，在那裡刪除。
> 刪除分兩種——只刪個人資料（便利貼留著但不再能追溯投稿者），
> 或連同該會員的所有便利貼一起撤下。
>
> 停權名單（`banned_users`）不在刪除範圍內：否則被封鎖的人申請刪除個資就等於解除封鎖。
> 上面「保存多久」的停權紀錄一條就是為此而寫，**請法務確認這個例外站得住**
> （防止再次違規可視為原蒐集目的「避免惡意投稿」的延伸）。

您也可以隨時請求撤下您已展示的便利貼。

**若您選擇不提供 LINE 帳號資料**，您仍然可以瀏覽便利貼牆、使用編輯器製作
便利貼並下載成圖片保存，但**無法送出便利貼參加展示**。

但請理解，網際網路傳輸無法保證絕對安全，本公司僅能盡合理之努力保護您的資料。
